Device handling: same auto-detect as slm125m/train_dpo.py's get_device() — check

  - 2-3 epochs only
  - LR 1e-5 for the 125M full-parameter run
  - LR 2e-5 for the Gemma 2B QLoRA run
  - Reasonable defaults for batch-size/grad-accum matching finetune_local.py's pattern
